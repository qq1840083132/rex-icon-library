# rex-icon-library

Rex 订阅补充图标库：Paramount+、HBO Max、ViuTV、芒果TV，补良友库里挂掉的图。

## 在 Rex 里订阅

在 Rex 的图标库 / 图标订阅入口添加以下地址：

```
https://raw.githubusercontent.com/qq1840083132/rex-icon-library/main/rex-icon-supplement.json
```

刷新后搜索 `Paramount`、`HBO Max`、`ViuTV`、`芒果TV` 即可找到。

## 包含的图标

- Paramount+ / 派拉蒙+ — 蓝字透明底 PNG
- HBO Max — 2025 版黑字 PNG，另有 HBO Max-白（白色版 WebP，深色底用）
- ViuTV — 蓝字透明底 PNG
- 芒果TV / 芒果tv — 橙色 M + 芒果tv，透明底 PNG

图源为 Wikimedia 官方 logo，稳定直链，不走已停用的 emby-icon.vercel.app。
